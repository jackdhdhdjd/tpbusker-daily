# 臺北市街頭藝人 每日照片偵測與展演檢視系統 (雙商圈全覽：西門町 ＋ 信義區 雙核心合一版)

專為臺北市最熱門兩大街頭藝人聚落打造：
1. **西門町商圈**：[西門徒步區 (placeRid=1)](https://tpbusker.gov.taipei/tpbusker/venue-detail?placeRid=1) ＋ [西門街藝之星 (placeRid=101)](https://tpbusker.gov.taipei/tpbusker/venue-detail?placeRid=101)
2. **信義商圈**：[信義徒步區 (placeRid=104)](https://tpbusker.gov.taipei/tpbusker/venue-detail?placeRid=104) ＋ [信義街藝之星 (placeRid=102)](https://tpbusker.gov.taipei/tpbusker/venue-detail?placeRid=102)

---

## 🌟 核心雙商圈全覽功能

1. **雙商圈合一（一次看當天西門町與信義區所有藝人）**：
   - 預設【雙商圈全覽 🌟】，當天同時載入西門町與信義區共 55 處點位演出排程與藝人大頭照！
   - 提供快捷標籤隨時切換：
     - **【雙商圈全覽 🌟】**
     - **【🏛️ 西門町商圈】** (漢中街、武昌街、真善美廣場)
     - **【🏙️ 信義商圈】** (香堤大道、威秀影城、新光三越 A4/A8/A9/A11、微風松高、BELLAVITA)
     - **【⭐ 街藝之星特選】** (雙商圈特選頂尖街藝之星)
2. **商圈專屬識別徽章與抽籤精準過濾**：
   - 藝人卡片一目瞭然標註 `🏛️ 西門町`（藍標）或 `🏙️ 信義區`（紫標）。
   - 文化局認證街藝之星特別加註金色流光 `⭐ 街藝之星` 徽章。
   - **精準過濾文化局抽籤名冊**：主卡片僅呈現真正正選中籤演出藝人（`Rank 1`），自動排除候補備取人員（如 11/7 信義街藝之星精準顯示正選「嗨小杜」，備取人員陳相合、李秋潤則標示於卡片下方備取欄），並完整解構雙人組/樂團成員名冊（如 11/5 信義 A 點「于熙」與「Tyler_太熱」雙卡片並陳）。
3. **內建雙商圈官方點位地圖（Base64 自帶免圖檔遺失）**：
   - 西門町 20 點位地圖（A~F 點、1~14 號點）。
   - 信義區 32 點位地圖（香堤大道、威秀、三越全區點位圖）。
   - 可一鍵切換檢視並支援全螢幕放大燈箱。
2. **自動輪詢檢測（即時蹲點）**：
   - 支援 30秒 / 1分鐘 / 5分鐘 定時偵測。
   - 綠燈呼吸閃爍即時狀態顯示。
   - 發現新照片時可觸發音效提醒。
3. **靈活日期切換**：
   - 提供「今日」、「明日」、「昨日」及自訂行事曆挑選器，可檢視全月份各日歷史或已排定檔期。
4. **多維度篩選與搜尋**：
   - 依表演點位（A點、B點、1~14號點等）篩選。
   - 依類別篩選（表演藝術類、視覺藝術類、創意工藝類）。
   - 支援關鍵字即時搜尋藝名、真實姓名、表演節目或描述。
   - 「僅顯示有照片」一鍵勾選切換。
5. **多場地支援**：
   - 預設聚焦西門徒步區（`placeRid=1`），亦可下拉切換臺北市全區 81 處街頭藝人展演場地（如大安森林公園、信義區等）。
6. **名冊與照片連結匯出**：
   - 一鍵匯出當日有照片藝人名冊與照片直連網址清單。

## 🚀 快速啟動方式

### 方法一：使用內建 Python 聚合伺服器（推薦，極速 < 1秒，免跨域問題）

本專案附帶零相依性的 `server.py`（使用 Python 內建標準函式庫，**無需 `pip install` 任何套件**）：

```bash
cd C:\Users\jack\.gemini\antigravity\scratch\tpbusker-daily-detector
python server.py
```
或直接雙擊 **`點我啟動.bat`**。

- 終端機執行後，會自動在預設瀏覽器中開啟 `http://localhost:8000/`。
- 後端使用執行緒池同時抓取 20 個點位，並聚合為單一 API，秒級載入！
- **📱 手機同步查看**：若手機與電腦連接同一個 Wi-Fi，手機瀏覽器直接輸入 `http://10.185.143.57:8000/` 或點擊網頁右上角「手機看」掃描 QR Code 即可！

---

### 方法二：出門在西門町用手機 4G/5G 隨時看（免開電腦）

因為本系統是純靜態網頁且已內建全月份照片快取：
1. 開啟免費的 [Netlify Drop](https://app.netlify.com/drop)。
2. 將 `tpbusker-daily-detector` 整包資料夾拖入網頁中。
3. 5 秒內即可獲得一個專屬的 `https://xxxx.netlify.app` 永久網址。
4. 手機在西門町逛街時用 4G/5G 隨時可點開，還能加入手機主畫面像 App 一樣方便！

---

### 方法二：直接瀏覽器開啟 `index.html`

- 直接雙擊開啟 `index.html`。
- 若瀏覽器因安全政策出現 CORS 跨域提示，可點選頂部提示切換連線設定，或搭配方法一啟動。

---

### 方法三：Tampermonkey 油猴腳本（在官網頁面直接浮動檢視）

若您習慣直接在官方網站瀏覽：
1. 安裝 Chrome / Edge 擴充功能「Tampermonkey」。
2. 將 `tampermonkey.user.js` 內容加入腳本。
3. 進入 [https://tpbusker.gov.taipei/tpbusker/venue-detail?placeRid=1](https://tpbusker.gov.taipei/tpbusker/venue-detail?placeRid=1) 頁面。
4. 右下角會出現 **「📸 偵測今日藝人照片」** 浮動按鈕，點擊即可無跨域限制直接彈出當日照片牆！

## 📂 檔案架構

- `index.html`：現代化響應式 UI，採用 Tailwind CSS、FontAwesome、原生 JavaScript 開發。
- `server.py`：純 Python 標準庫編寫的本地伺服器與 API 聚合代理器。
- `tampermonkey.user.js`：適用於官方網站的油猴使用者腳本。
- `README.md`：系統說明文件。
